# Banco de Dados MySQL

Projeto acadêmico desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas, com foco em modelagem de banco de dados e consultas SQL.

## Sobre o projeto

O projeto consiste na criação de um banco de dados para gerenciamento de uma academia, envolvendo clientes, endereços, instrutores, treinos e exercícios.

Durante o desenvolvimento, foram trabalhados conceitos de modelagem relacional, criação de tabelas, definição de tipos de dados, chaves primárias e estrangeiras, relacionamentos, inserção de registros e consultas SQL.

## Estrutura do banco

O banco de dados possui tabelas relacionadas a:

- Clientes
- Endereços
- Instrutores
- Treinos
- Exercícios
- Clientes e treinos
- Treinos e exercícios

## Consultas SQL

O projeto inclui consultas utilizando:

- `INNER JOIN`
- `GROUP BY`
- `COUNT`
- `AVG`
- `WHERE`

## Tecnologias utilizadas

- MySQL / MariaDB
- SQL
- Modelagem de banco de dados
